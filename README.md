# Солнечная система

Интерактивный сайт-путеводитель по Солнечной системе в стиле ретро-постера: от Солнца до Плутона.

**Сайт:** https://polina-web1818.github.io/solar-system/

## Что умеет сайт

- **Главный экран** — анимированная система на canvas: планеты летают по наклонным орбитам. При наведении планета увеличивается, её орбита подсвечивается, а система встаёт на паузу. По клику (или тапу) — переход к разделу планеты.
- **Разделы планет** — Солнце, 8 планет и Плутон («бывшая планета, с 2006 года — карликовая»). В каждом разделе большая планета и 4 факта.
- **Навигация** — прокрутка «примагничивается» к экранам (одно движение = один раздел), справа навигация точками с подсветкой текущего раздела.
- **Калькулятор веса** — сколько ты весишь на каждой планете.
- **Калькулятор возраста** — сколько тебе лет на каждой планете.
- **«Сколько лететь»** — время пути до планеты пешком, на машине, самолёте, ракете или со скоростью света, с анимацией полёта.
- **Адаптив** — отдельная раскладка для телефона.

## Технологии

HTML, CSS и ванильный JavaScript — без фреймворков, библиотек и сборщиков.

- **Canvas** — рисование и анимация планет.
- **IntersectionObserver** — подсветка текущего раздела в навигации и остановка анимации, когда главный экран не виден.
- **CSS scroll snap** — прокрутка по экранам.

## Структура файлов

```
index.html            разметка страницы
css/style.css         все стили; палитра — в переменных :root
js/planets-data.js    данные: планеты, факты, гравитация, периоды, расстояния
js/planet-art.js      рисование планет и Солнца на canvas
js/hero.js            анимация главного экрана, наведение и клик по планетам
js/sections.js        разделы планет: разметка из данных и большие рисунки
js/nav.js             навигация точками
js/calculators.js     калькуляторы веса и возраста
js/travel.js          калькулятор «Сколько лететь»
js/main.js            точка входа: запускает все модули
CLAUDE.md             описание проекта и правил для ИИ-ассистента
```

## Как запустить локально

Скачать репозиторий и открыть `index.html` в браузере. Или в VS Code: расширение **Live Server** → кнопка **Go Live**.
