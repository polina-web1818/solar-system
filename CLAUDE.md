## Правила задания (обязательно)
- Только HTML, CSS и ванильный JavaScript. Без фреймворков, сборщиков, npm и библиотек (Three.js тоже нельзя).
- Стили только в `css/`, скрипты только в `js/`.
- Работа идёт итерациями: одна итерация = одно небольшое улучшение = один коммит.
- Коммиты на русском, формат: «Итерация N: что сделано».
- После коммита — push в `main` (GitHub Pages публикуется из `main`, `/ (root)`).

## Пользователь
- Не программист, учится. Объяснять технические термины простыми словами, с английским термином в скобках.
- Коротко и по делу, без воды. Критику давать честно, списком плюсов и минусов.

## Стиль (по референсам в папке references/)
- Ретро-постер: плоский вектор, мазки кистью, тень-полумесяц, полутоновые точки, зерно поверх страницы.
- Палитра: тёмно-синий фон #17283f / #0f1b2d, кремовый #f1e4c8, красный #c2412d,
  оранжевый #e8862a, горчичный #e3a83b, бирюзовый #2f6f68, голубой #8fb9cf.
- Шрифты: Rubik Mono One (заголовки), Oswald (подписи, капс с разрядкой), Manrope (текст).
- Декор: тонкие кремовые орбиты, наклонные линии, треугольная полутоновая сетка.
- Десктоп: наклонные эллиптические орбиты вокруг Солнца. Телефон: Солнце в левом верхнем углу, планеты по диагонали.

## Структура кода
- `index.html` — разметка.
- `css/style.css` — все стили, переменные палитры в `:root`.
- `js/planets-data.js` — массив PLANETS (имя, период, размер, цвета, тип узора).
- `js/planet-art.js` — рисование планет и Солнца на canvas (спрайты).
- `js/hero.js` — анимация главного экрана (модуль Hero).
- `js/main.js` — точка входа.

## План итераций
1. ✅ Главный экран: анимированная система в ретро-стиле.
2. Разделы планет (Солнце → Меркурий … → Нептун → Плутон «бывшая планета»): большая планета + 3–4 факта.
3. Scroll snap (одна прокрутка = одна планета) + навигация точками сбоку.
4. Клик по планете на главном экране → плавный переход к её разделу; подсветка при наведении.
5. Анимации появления фактов (IntersectionObserver).
6. Блок «Ты и космос»: калькулятор веса на планетах.
7. Калькулятор возраста на планетах.
8. Калькулятор «сколько ехать»: пешком, машина, самолёт, вертолёт, ракета, свет.
9. Адаптив под телефон (известно: Плутон заезжает под текст, край Солнца слишком колючий, подпись Меркурия налезает на Солнце).
10. readme.md + правки по отзывам одногруппников.
